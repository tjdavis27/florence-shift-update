# Florence Shift Update Mobile v2.1.2

## Giveaway format

Each giveaway now has one Giveaway Name and multiple item lines.

Final output:

September Promo:
2 - Keychain
1 - T-shirt - donation prize

Use:
- Giveaway Name
- + Add Item
  - Quantity
  - Item
  - Notes (optional)

Multiple giveaways can still be logged on one shift.

Old v2.1 entries migrate automatically:
Promotion -> Giveaway Name
How Many Given -> Quantity
What Was Won -> Item
Notes -> item notes

## Training

Accomplishment is now optional.

Required:
- Employee
- Role Trained On

Optional:
- Accomplishment

Examples:
Training: Justin - CXS2
Training: Justin - CXS2 - practiced booking emails
